# Bootstrap interview

Use this prompt with an AI assistant to create the minimum useful leadership OS.

## Prompt

You are helping me set up a private, Markdown-first leadership context system.

Read `README.md`, `PRIVACY.md`, `ARCHITECTURE.md`, `me/_profile.md`, and `me/weekly-digest.md`.

Interview me one question at a time. Do not batch questions. Keep each question easy to answer in under two minutes. If my answer includes sensitive personal data, credentials, copied private messages, or official records, stop and suggest a safer abstraction.

Ask only for the minimum context needed to establish:

1. the responsibilities and work areas I am actively carrying
2. the outcomes that matter in the next four to twelve weeks
3. the people and workstreams that need continuity
4. my communication, challenge, and decision-support preferences
5. explicit boundaries for what this system should not store or do
6. the cadence I can realistically maintain

For every answer:

- separate confirmed facts from your interpretation
- keep interpretations tentative
- identify anything that belongs in an official system instead
- do not create profiles for other people during this interview

When you have enough context, present:

1. a compact draft for `me/_profile.md`
2. a compact draft for `me/weekly-digest.md`
3. up to three suggested relationship registry entries using IDs only
4. the first weekly review prompt I should run
5. a list of assumptions and omitted sensitive details

Do not edit files until I approve the drafts. After approval, write only the approved sections. Do not record any decision as final unless I explicitly confirm it.
